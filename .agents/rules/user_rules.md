# 기본 작업 원칙

1. **지시한 범위 내에서만 작업 (오버엔지니어링 금지)**: 사용자가 명령한 내용에 대해서만 작업하며, 임의의 부가 작업이나 파일 수정 금지.
2. **언어별 지원 고려**: 다국어(한국어, 영어 등 대상 언어)를 항상 염두에 두고 구조화 및 개발.
3. **화면 테스트 절대 금지**: 시간이 오래 걸리는 브라우저/화면 UI 테스트는 일절 실행하지 않음.
4. **작업 완료 후 에뮬레이터 즉시 반영 필수**: 작업이 끝나면 항상 안드로이드 에뮬레이터에 실시간 반영(핫 리로드/핫 리스타트).
5. **다크/라이트 모드 동시 대응**: UI 작업 시 다크/라이트 테마 모두 완벽 지원.
